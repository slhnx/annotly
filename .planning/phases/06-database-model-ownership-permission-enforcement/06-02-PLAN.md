<objective>
Implement the core persistent schema models (`User`, `Project`, `Canvas`, `Annotation`, `AnnotationReply`) with relational integrity, indexes, and lifecycle cascades (Plan 06-02).

Purpose: Establish the structural database foundation for zero-install review canvases, element-anchored pins, device metadata capture, and threaded discussions.
Output: Extended `prisma/schema.prisma`, synchronized PostgreSQL database via Prisma, updated `ProjectService`, and relational integration test suite `tests/schema-models.test.ts`.
</objective>

<tasks>
<task id="1" name="Expand prisma/schema.prisma with core relational models">
Define `User`, `Canvas`, `Annotation`, `AnnotationReply`, and `AnnotationStatus` in `prisma/schema.prisma`.
- Connect `User` to `Project` (1-to-many, cascade delete)
- Connect `Project` to `Canvas` (1-to-many, cascade delete)
- Connect `Canvas` and `Project` to `Annotation` (1-to-many, cascade delete)
- Connect `Annotation` to `AnnotationReply` (1-to-many, cascade delete)
- Support both authenticated users (`userId`) and guest reviewers (`authorName`, `authorEmail`) on `Annotation` and `AnnotationReply`
- Store element-relative percentage offsets (`offsetX`, `offsetY`) and viewport metrics (`viewportWidth`, `viewportHeight`, `devicePixelRatio`)
- Add appropriate indexes on all foreign keys, status fields, and unique tokens
</task>

<task id="2" name="Synchronize database schema and update ProjectService integration">
Run `prisma db push` and `prisma generate` to update PostgreSQL tables and TypeScript client types.
Update `ProjectService.createProject` to:
- Automatically ensure/upsert the owner in `User` model to maintain relational integrity
- Atomically create the initial default `Canvas` via Prisma nested writes
- Handle cascade deletion cleanly
</task>

<task id="3" name="Implement comprehensive schema models & relational integration test suite">
Create `tests/schema-models.test.ts` testing:
- Creation of User, Project, Canvas, Annotation, and AnnotationReply
- Validation of element-relative coordinates (`offsetX`, `offsetY`) and 5-tier selector metadata
- Multi-reply thread hierarchy on annotations
- Cascade deletion: deleting a Project deletes its Canvases, Annotations, and AnnotationReplies
- Isolation: guest vs registered reviewer attribution
</task>
</tasks>
