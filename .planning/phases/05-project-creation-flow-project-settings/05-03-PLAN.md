<objective>
Build the dedicated project detail/overview page at `/dashboard/projects/[projectId]` along with a non-leaking not-found/unauthorized state.

Purpose: Give project owners a central hub for each website project showing target site identity, shareable review link, comment/triage metrics, recent activity, quick navigation to project settings, and a primary action to launch the live review canvas.
Output: `/dashboard/projects/[projectId]` route, `not-found.tsx`, modular `project-detail/*` components, and navigation links from project cards/rows.
</objective>

<tasks>
<task id="1" name="Build modular project detail header, review link card, metrics, and activity components">
Create under `features/projects/components/project-detail/`:
- `project-detail-header.tsx`: site favicon/monogram, project title, `ProjectStatusBadge`, target website external link, "Project Settings" button (`/dashboard/projects/[projectId]/settings`), and primary "Open Review Canvas" button.
- `project-review-link-card.tsx`: shareable review URL display, copy-link button with copied feedback, and review access status badge.
- `project-overview-metrics.tsx`: 4-card summary grid (Open Comments, Resolved Comments, Active Reviews, Resolution Rate) using shadcn `Card`.
- `project-activity-card.tsx`: latest comment/review activity timeline or empty state prompting the user to share the review link.
</task>

<task id="2" name="Create /dashboard/projects/[projectId] page and non-leaking not-found boundary">
Create `app/(dashboard)/dashboard/projects/[projectId]/page.tsx` and `app/(dashboard)/dashboard/projects/[projectId]/not-found.tsx`. When `getProjectByIdAction(projectId)` fails (whether nonexistent or owned by another user), invoke `notFound()` so the response does not leak project existence.
</task>

<task id="3" name="Link dashboard project cards, rows, and breadcrumbs to project detail view">
Update `project-card.tsx`, `project-row.tsx`, `recent-projects-card.tsx`, and `components/dashboard/breadcrumbs.tsx` so clicking a project name or "Project Details / Settings" navigates to `/dashboard/projects/[projectId]` and breadcrumbs format project sub-routes cleanly.
</task>
</tasks>
